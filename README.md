# warp-weft

This repository was evaluated as a potential foundation for Warp,
a typed commerce workflow runtime built by Lamar Tech.

After evaluation, we discovered that Weft's durable execution is
provided by Restate (MIT SDK). We chose to build Warp directly on
Restate for full license clarity and complete ownership of the
commerce DSL and compiler.

This repository is retained as a reference only. Active Warp
development is at github.com/yasirlts/warp (private).

Built on WeaveMindAI/weft (O'Saasy License — see LICENSE).
Evaluated May 2026. Not used in production.
