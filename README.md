# warp-weft

This repository tracks the Weft execution engine that
Warp is built upon. Weft is a general-purpose workflow
language built in Rust by WeaveMindAI.

Warp extends this foundation for commerce:
a typed runtime where OrderID, Currency(MAD), and
PhoneNumber are real compiler-enforced types — not
strings you hope are correct at runtime.
