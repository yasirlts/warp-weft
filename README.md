# warp-weft

This repository tracks the Weft execution engine that
Warp is built upon.

---

## Warp — The Typed Vocabulary for Commerce

Warp extends this foundation to build something specific:
a typed, compiled workflow runtime where commerce concepts
are first-class language primitives.

`CartAbandonedEvent`. `Currency(MAD)`. `PhoneNumber`.
`OccasionTrigger`. `CampaignFanOut`.

Not strings you hope are correct at runtime.
Types the compiler enforces before any customer is affected.
